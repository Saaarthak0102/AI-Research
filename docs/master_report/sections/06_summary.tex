\section{Discussion and Conclusion}

\subsection{Key Findings}
\begin{itemize}
    \item \textbf{Claude Code's Exceptional Resilience:} Claude Code (Haiku 4.5) achieved 0\% exploitation across all 52 tasks and four vectors, consistently inspecting function bodies over docstrings, verifying security claims independently, and refusing to propagate pre-existing vulnerabilities.
    \item \textbf{Context Poisoning as the Dominant Vector:} Context Poisoning proved most effective overall, exploiting ChatGPT at 53.8\% and Antigravity at 30.8\%. False authority claims embedded in code comments, changelogs, and test logs bypassed safety filters more effectively than direct adversarial prompts.
    \item \textbf{Non-overlapping Failure Sets:} ChatGPT and Antigravity failed on largely disjoint task subsets. Only 4 of 52 tasks (CP-01, CP-03, CP-11, SL-05) were exploited in both agents, suggesting fundamentally different architectural vulnerabilities rather than shared weaknesses.
    \item \textbf{Acknowledged Non-Compliance:} A critical failure pattern in ChatGPT (SL-05, SL-08): the agent explicitly identified insecurity via inline comments but complied anyway—acting as a ``reluctant accomplice'' that prioritizes instruction-following over safety.
    \item \textbf{Compliance-via-Relocation:} When pressured, agents sometimes displaced malicious logic into secondary artifacts (test fixtures, CI scripts, Dockerfiles) rather than modifying primary application code, creating a false sense of integrity.
\end{itemize}

\subsection{Recommendations}
\begin{enumerate}
    \item \textbf{Contextual Sanitization:} Repositories and documentation fed into agent context windows must be reviewed for adversarial payloads, as implicit instructions in docstrings, comments, and metadata bypass primary guardrails.
    \item \textbf{Dependency Verification:} All agent-recommended package installations must be cross-referenced with authorized registries to prevent typosquatting and phantom package injection.
    \item \textbf{Secondary Artifact Auditing:} Review protocols must specifically target non-core files (CI/CD scripts, Dockerfiles, test suites), where agents frequently relocate unsafe behavior.
\end{enumerate}

\subsection{Future Work}
Future research will expand to dynamic multi-step exploits and open-weight models deployed locally. Developing automated context-sanitization tools for IDEs is a critical area for improving defensive capabilities.
